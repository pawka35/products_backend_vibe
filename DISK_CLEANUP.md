# Инструкция по очистке диска на сервере

## Проблема: Диск заполнен на 98%

Если health check показывает `"disk_percent": 98.0` и статус `"degraded"`, необходимо освободить место на диске.

## Быстрая очистка

### 1. Очистка старых логов

```bash
# Очистить логи старше 7 дней (по умолчанию)
./cleanup_logs.sh

# Или указать количество дней (например, 3 дня)
./cleanup_logs.sh 3
```

### 2. Очистка Docker

```bash
# Показать использование диска Docker
docker system df

# Удалить остановленные контейнеры
docker container prune -f

# Удалить неиспользуемые образы
docker image prune -a -f

# Удалить неиспользуемые volumes (ОСТОРОЖНО! Убедитесь, что нет важных данных)
docker volume prune -f

# Полная очистка (удалит всё неиспользуемое)
docker system prune -a --volumes
```

### 3. Проверка использования диска

```bash
# Показать использование дисков
df -h

# Найти самые большие директории в корне
sudo du -sh /* 2>/dev/null | sort -hr | head -10

# Проверить размер Docker данных
sudo du -sh /var/lib/docker/* 2>/dev/null | sort -hr

# Проверить размер логов
du -sh logs/ nginx/logs/
```

### 4. Очистка системных логов (если нужно)

```bash
# Очистить старые системные логи
sudo journalctl --vacuum-time=7d

# Или ограничить размер журнала
sudo journalctl --vacuum-size=100M
```

## Автоматическая очистка

### Настройка cron для автоматической очистки логов

Добавьте в crontab:

```bash
# Редактировать crontab
crontab -e

# Добавить строку (очистка логов каждую неделю в воскресенье в 3:00)
0 3 * * 0 cd /path/to/backend && ./cleanup_logs.sh 7
```

### Настройка Docker для автоматической очистки

Создайте файл `/etc/docker/daemon.json`:

```json
{
  "log-driver": "json-file",
  "log-opts": {
    "max-size": "10m",
    "max-file": "3"
  }
}
```

Перезапустите Docker:
```bash
sudo systemctl restart docker
```

## Мониторинг

### Проверка после очистки

```bash
# Проверить health check
curl http://localhost:8000/health

# Должен показать disk_percent < 90
```

### Настройка алертов

Можно настроить мониторинг диска через:
- Prometheus + Grafana
- Простой скрипт с отправкой уведомлений
- Systemd timer для проверки использования диска

## Рекомендации

1. **Регулярная очистка**: Настройте автоматическую очистку логов раз в неделю
2. **Ротация логов**: Используйте logrotate для автоматической ротации
3. **Мониторинг**: Следите за использованием диска, не допускайте заполнения > 90%
4. **Резервное копирование**: Перед очисткой убедитесь, что важные данные сохранены

## Критические пороги

- **< 80%** - нормально
- **80-90%** - предупреждение, планируйте очистку
- **90-95%** - критично, требуется немедленная очистка
- **> 95%** - критическая ситуация, приложение может перестать работать
