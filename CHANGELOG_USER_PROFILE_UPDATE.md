# Changelog: Добавление возможности обновления профиля и пароля пользователем

**Дата:** 3 ноября 2025  
**Версия:** 1.2.0  
**Автор:** Система разработки

## 📋 Описание изменений

Добавлена возможность для пользователей самостоятельно изменять свои данные (username, email) и пароль. Это улучшает пользовательский опыт и снижает нагрузку на администраторов.

## 📊 API Изменения

### Новые эндпоинты

#### 1. PUT /auth/me
Обновление профиля пользователя

**Запрос:**
```json
{
    "username": "new_username",  // необязательно
    "email": "new@example.com"   // необязательно
}
```

**Ответ (200 OK):**
```json
{
    "message": "Профиль успешно обновлен",
    "user": {
        "id": 1,
        "username": "new_username",
        "email": "new@example.com",
        "role": "customer",
        "is_active": true,
        "created_at": "2024-01-01T12:00:00Z",
        "updated_at": "2024-01-02T14:30:00Z"
    }
}
```

**Возможные ошибки:**
- 400 - Необходимо указать хотя бы одно поле
- 400 - Username уже занят
- 400 - Email уже занят
- 401 - Не авторизован

#### 2. PUT /auth/me/password
Изменение пароля пользователя

**Запрос:**
```json
{
    "current_password": "OldPass123!",
    "new_password": "NewPass456!"
}
```

**Ответ (200 OK):**
```json
{
    "message": "Пароль успешно изменен",
    "user": {
        "id": 1,
        "username": "john_doe",
        "email": "john@example.com",
        "role": "customer",
        "is_active": true,
        "created_at": "2024-01-01T12:00:00Z",
        "updated_at": "2024-01-02T15:00:00Z"
    }
}
```

**Возможные ошибки:**
- 400 - Неверный текущий пароль
- 422 - Слабый новый пароль
- 401 - Не авторизован

## 🔒 Безопасность

### Проверки обновления профиля
1. ✅ JWT токен валидный
2. ✅ Пользователь может изменять только свои данные
3. ✅ Username уникален
4. ✅ Email уникален
5. ✅ Валидация всех входных данных

### Проверки изменения пароля
1. ✅ JWT токен валидный
2. ✅ Текущий пароль верен
3. ✅ Новый пароль соответствует требованиям
4. ✅ Пароль хешируется перед сохранением
5. ✅ Токен остается валидным

### Логирование
- Все операции обновления профиля логируются
- Изменения пароля записываются в security.log
- Сохраняется информация о пользователе, времени и IP
