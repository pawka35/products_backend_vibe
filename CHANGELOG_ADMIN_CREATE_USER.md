# Changelog: Добавление возможности создания пользователей администратором

**Дата:** 3 ноября 2025  
**Версия:** 1.1.0  
**Автор:** Система разработки

## 📋 Описание изменений

Добавлена возможность для администраторов создавать новых пользователей с любой ролью, включая роль администратора. Это позволяет гибко управлять пользователями системы без необходимости использовать обычную регистрацию.

## ✨ Новый функционал

### 1. Новая схема AdminUserCreate
**Файл:** `app/schemas/admin_schemas.py`

Добавлена новая Pydantic схема для создания пользователей администратором:
```python
class AdminUserCreate(BaseModel):
    username: str
    email: EmailStr
    password: str
    role: UserRole  # Может быть любая роль, включая admin
```

**Особенности:**
- ✅ Нет валидации, запрещающей роль admin
- ✅ Полная валидация пароля (минимум 8 символов, сложность)
- ✅ Валидация email через EmailStr
- ✅ Ограничения на длину username (3-50 символов)

## 📊 API Изменения

### Новый эндпоинт
```
POST /admin/users
```

**Требования:**
- Авторизация: Bearer Token (admin)
- Content-Type: application/json

**Запрос:**
```json
{
    "username": "new_user",
    "email": "user@example.com",
    "password": "SecurePass123!",
    "role": "customer"
}
```

**Ответ (200 OK):**
```json
{
    "id": 10,
    "username": "new_user",
    "email": "user@example.com",
    "role": "customer",
    "is_active": true,
    "created_at": "2024-01-01T12:00:00Z",
    "updated_at": null
}
```

**Возможные ошибки:**
- 400 - Пользователь с таким username уже существует
- 400 - Пользователь с таким email уже существует
- 403 - Требуются права администратора
- 422 - Невалидные данные
